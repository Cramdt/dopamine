# ⚡ドーパミン⚡

ドーパミンが出るやつを詰め込みまくったAndroidアプリです。
開いた瞬間からスロット、ガチャ、ルーレットが回りまくります。

## ダウンロード

[Releases](../../releases) から最新の `dopagaki.apk` をダウンロードしてインストールしてください。

※ インストール時に「提供元不明のアプリ」の許可が必要な場合があります（Playストア外のアプリのため）。

## 遊べるもの

- 🎰 **スロット** — 3リール、7️⃣×3で100倍ジャックポット、ニアミス演出あり
- 🎁 **ガチャ** — 全156種コレクション、新レアリティLRあり、100回天井つき
- 👆 **連打クリッカー** — コンボ倍率＆FEVERモード
- 🗃️ **宝箱** — 3つから選んで開封
- 🪙 **ダブルアップ** — 勝ち分を賭けて2倍 or 0、連続挑戦可
- 🃏 **ハイ＆ロー** — 連勝で倍率アップ
- 🎡 **運命のルーレット** — ×50マスあり（甘め設計）
- 🎁 ログインボーナス＆放置報酬、ラッキータイム（全配当1.5倍）、実績20種
- ⚡ **オート＆倍速（v1.2追加）** — スロットのオート回転、ガチャのオート連、連打オートタップ。全ゲームに×1／×2／×4の倍速対応で、オートと併用すれば超高速で回せます

## 動作環境

- Android 10 以上
- 広告なし・課金なし・通信なし（端末の中だけで完結します）

## 注意

アプリ内のお金（ドパコイン）は全部ゲーム内通貨です。実際のお金とは一切関係ありません。

## v2.0での変更点（セキュリティ強化版）

外部のAIによる脆弱性診断を受けた結果をもとに、チート対策を入れた通常版です。

- 開発用ハックパネルを完全に廃止（通常版に一本化）
- セーブデータに改ざん検知を導入（HMAC-SHA256署名＋バックアップ復旧、鍵はAndroid Keystore内）
- 端末の時刻を進める操作では放置報酬・ログインボーナス・生活保護が増えないよう、二重時計チェックを導入
- 抽選の乱数を `SecureRandom` に変更
- コード難読化（R8）と、アプリ自身の署名を起動時に照合する自己検証を追加
- 以前のバージョンのセーブデータはそのまま引き継がれます

※ 完全オフラインのアプリなのでチートを100%防ぐことはできませんが、簡単に書き換えられないよう対策しています。
